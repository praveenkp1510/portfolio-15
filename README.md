# K P Praveen - Frontend Developer Portfolio

A modern, responsive, and performant portfolio website built with React, Vite, and Tailwind CSS.

## 🚀 Features

### 🎨 Modern UI/UX
- **Premium Design**: Clean, minimal, and professional interface
- **Dark/Light Theme**: Seamless theme switching with system preference detection
- **Smooth Animations**: Framer Motion powered micro-interactions and page transitions
- **Responsive Design**: Fully responsive across all devices and screen sizes

### ⚡ Performance Optimized
- **Lazy Loading**: Code splitting with React.lazy and Suspense
- **Image Optimization**: Lazy loading images with intersection observers
- **Memoization**: React.memo, useMemo, and useCallback for optimal rendering
- **Bundle Optimization**: Tree shaking and minimal dependencies

### 🛠 Technical Features
- **Component Architecture**: Scalable folder structure with separation of concerns
- **Custom Hooks**: Reusable logic for scroll, filtering, and theme management
- **TypeScript Ready**: Full TypeScript support (can be easily migrated)
- **Accessibility**: ARIA labels, semantic HTML, and keyboard navigation
- **Error Boundaries**: Graceful error handling and user feedback

### 📱 Sections
- **Hero**: Eye-catching introduction with animated profile
- **Projects**: Filterable project showcase with tech stacks
- **About**: Professional summary and resume download
- **Experience**: Interactive timeline of work history
- **Skills**: Animated skill bars with proficiency levels
- **Contact**: Functional contact form with validation

## 🛠 Tech Stack

### Frontend
- **React 19** - UI library with modern hooks
- **Vite** - Fast build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **React Router** - Client-side routing

### Development Tools
- **ESLint** - Code linting and formatting
- **PostCSS** - CSS processing
- **Day.js** - Date manipulation
- **React Icons** - Icon library

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/praveenkp1510/portfolio-15.git
cd portfolio-15
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173/portfolio-15/`

### Building for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
